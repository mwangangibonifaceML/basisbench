# basisbench
A detailed investigation of polynomial, Fourier and neural representations for real-world time-series forecasting.

This project asks:

Can the inductive bias of a mathematical basis improve time-series forecasting compared with a conventional neural network?

Models:
- Taylor/Polynomial network.
- Fourier network.
- Neural Network

Each model is implemented in Pytorch.

The implementations are compared in terms of:
- forecasting accuracy
- convergence
- gradient behavior
- numerical stability
- computational cost
